    Best Practices¶

    Development¶

    1. Bulkify Code: Handle collections, not single records
    2. SOQL Efficiency: Avoid queries in loops
    3. Governor Limits: Stay within limits
    4. Testing: 75%+ code coverage with quality tests
    5. Error Handling: Implement try-catch blocks
    6. Asynchronous Processing: Use for long-running operations

    Integration¶

    1. API Limits: Monitor and optimize API usage
    2. Authentication: Use OAuth for security
    3. Error Handling: Implement retry logic
    4. Idempotency: Design for duplicate prevention
    5. Logging: Comprehensive error logging
    6. Rate Limiting: Respect API rate limits

    Governor Limits¶

    Key Limits¶

    • SOQL queries: 100 (sync), 200 (async)
    • DML statements: 150
    • CPU time: 10,000ms (sync), 60,000ms (async)
    • Heap size: 6MB (sync), 12MB (async)
    • Callouts: 100
    • Email invocations: 10 (single), unlimited (mass)
