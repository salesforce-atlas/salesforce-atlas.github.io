    Experience Cloud¶

    Overview¶

    Salesforce Experience Cloud (formerly Community Cloud) enables organizations to create branded digital experiences for customers, partners, and employees using Salesforce data and functionality.

    Experience Types¶

    Customer Community¶

    • Self-service portals
    • Case management
    • Knowledge base access
    • Order tracking
    • Account management

    Partner Community¶

    • Deal registration
    • Lead distribution
    • Co-selling collaboration
    • Partner onboarding
    • Performance tracking

    Employee Community¶

    • Internal collaboration
    • Knowledge sharing
    • Team workspaces
    • Recognition programs
    • HR services

    Core Features¶

    Site Builder¶

    • Drag-and-drop components
    • Lightning Web Components (LWC)
    • Responsive design
    • Template customization
    • SEO optimization

    Branding & Theming¶

    • Custom themes
    • Brand colors and fonts
    • Logo and imagery
    • Mobile optimization
    • Accessibility compliance

    User Management¶

    • External user licenses
    • Profile and permission sets
    • Role hierarchy
    • Sharing rules
    • Guest user access

    Templates¶

    Standard Templates¶

    • Aloha: Modern, clean design
    • Customer Service (Napili): Service-focused
    • Partner Central: Partner relationship management
    • Build Your Own: Custom Lightning template

    Security & Sharing¶

    External Sharing¶

    • Sharing sets
    • External organization-wide defaults
    • Community-specific sharing rules
    • Record access for external users

    Authentication¶

    • Self-registration
    • Social sign-on (Google, Facebook, LinkedIn)
    • Single sign-on (SSO)
    • Multi-factor authentication (MFA)
    • Password policies

    Content Management¶

    CMS (Content Management System)¶

    • CMS content
    • Content delivery
    • Multi-language support
    • Content versioning
    • Content targeting

    Knowledge Base¶

    • Article publishing
    • Article feedback
    • Search functionality
    • Article categories
    • Featured articles

    Analytics & Reporting¶

    Community Analytics¶

    • Page views and engagement
    • User activity tracking
    • Login frequency
    • Search metrics
    • Content performance

    Custom Dashboards¶

    • Community-specific reports
    • Real-time analytics
    • Member insights
    • Adoption metrics

    Customization¶

    Development Options¶

    • Lightning Web Components (LWC)
    • Aura Components
    • Visualforce pages
    • Custom CSS
    • JavaScript integration

    Third-Party Integration¶

    • Google Analytics
    • Marketing automation
    • Payment gateways
    • Chat and messaging
    • Social media

    Best Practices¶

    1. User Experience: Intuitive navigation and design
    2. Performance: Optimize page load times
    3. Mobile-First: Responsive design
    4. Content Strategy: Regular updates and curation
    5. Security: Proper access controls

    Common Use Cases¶

    • Customer self-service portals
    • Partner relationship management (PRM)
    • Employee intranets
    • Event management sites
    • E-commerce storefronts
    • Learning management systems

    Licensing¶

    License Types¶

    • Customer Community: External customers
    • Customer Community Plus: Enhanced features
    • Partner Community: Channel partners
    • External Apps: Custom applications
    • Guest User: Unauthenticated access
