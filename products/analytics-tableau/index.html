    Analytics & Tableau¶

    Overview¶

    Salesforce offers powerful analytics capabilities through Tableau CRM (formerly Einstein Analytics) and Tableau, enabling organizations to visualize, analyze, and act on their data.

    Tableau CRM (Einstein Analytics)¶

    Core Concepts¶

    Datasets¶

    • Structured data collections
    • Data transformation
    • Data synchronization
    • External data integration
    • Recipe-based data prep

    Lenses¶

    • Data exploration tool
    • Ad-hoc analysis
    • Quick visualizations
    • Filtering and grouping
    • Save as dashboard

    Dashboards¶

    • Interactive visualizations
    • Multiple widgets
    • User-driven exploration
    • Mobile optimization
    • Sharing and collaboration

    Apps¶

    • Pre-built analytics templates
    • Industry-specific solutions
    • Custom app creation
    • App exchange

    Key Features¶

    Einstein Discovery¶

    • Automated insights
    • Predictive analytics
    • Machine learning models
    • What-if scenarios
    • Story-telling with data

    SAQL (Salesforce Analytics Query Language)¶

    • Advanced queries
    • Complex calculations
    • Data manipulation
    • Custom aggregations

    Data Integration¶

    • Salesforce data sync
    • External data connectors
    • CSV uploads
    • API-based integration
    • Real-time streaming

    Best Practices¶

    1. Data Quality: Clean, consistent data
    2. User Adoption: Training and enablement
    3. Performance: Optimize queries and filters
    4. Security: Proper access controls
    5. Governance: Standard naming conventions
    6. Mobile: Design for mobile users
    7. Storytelling: Clear, actionable insights

    Tableau CRM vs. Tableau¶

    Feature Tableau CRM Tableau
    Primary Use Salesforce-native analytics Enterprise BI platform
    Data Source Primarily Salesforce Any data source
    User Interface Salesforce Lightning Desktop/Web application
    AI/ML Einstein Discovery TabPy, R, Python integration
    Licensing Per user (Salesforce licenses) Per user (Tableau licenses)
    Deployment Cloud-based Desktop, Server, Cloud
