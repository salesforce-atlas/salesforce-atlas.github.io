    Object-Level Security¶

    Profiles¶

    • Object permissions (CRUD)

    • App access
    • System permissions
    • Administrative permissions

    Permission Sets¶

    • Extend profile permissions
    • No permission removal

    • Field visibility
    • Field editability
    • Profile-based
    • Permission set override

    Record-Level Security¶

    Organization-Wide Defaults (OWD)¶

    -Private - Public Read Only - Public Read/Write - Controlled by Parent - Public Read/Write/Transfer (Leads/Cases/Campaigns)

    Role Hierarchy¶

    • Organizational structure
    • Grant access up the hierarchy
    • Does not restrict access
    • Used with sharing rules

    Sharing Rules¶

    • Ownership-based: Share based on record owner
    • Criteria-based: Share based on field values
    • Read Only or Read/Write access
    • Expand access beyond OWD

    Manual Sharing¶

    • User-initiated sharing
    • Share button
    • Apex-managed sharing
    • Team sharing (Accounts, Opportunities)

    Territory Management¶

    • Geographic/product territories
    • Assignment rules
    • Territory hierarchy
    • Territory-based forecasting

    Apex Sharing¶

    • Programmatic sharing
    • Custom share objects (e.g., Account__Share)
    • RowCause for tracking
    • Recalculation considerations

    Compliance Frameworks¶

    GDPR (General Data Protection Regulation)¶

    • Right to access: Data portability
    • Right to be forgotten: Delete personal data
    • Data minimization: Collect only necessary data
    • Consent management: Track and manage consent
    • Breach notification: Within 72 hours

    Salesforce GDPR Tools¶

    • Individual object
    • Data classification
    • Consent management
    • Data deletion
    • Data portability

    HIPAA (Health Insurance Portability and Accountability Act)¶

    • PHI Protection: Protect health information
    • Access controls: Role-based access
    • Audit trails: Comprehensive logging
    • Encryption: Data at rest and in transit
    • Business Associate Agreement (BAA): Required with Salesforce

    SOC 2 (Service Organization Control)¶

    • Security
    • Availability
    • Processing integrity
    • Confidentiality
    • Privacy

    PCI DSS (Payment Card Industry Data Security Standard)¶

    • Do NOT store: CVV, PIN, full mag stripe
    • Tokenization: Store tokens, not cards
    • Encryption: Encrypt stored card data
    • Access control: Restrict cardholder data access

    SOX (Sarbanes-Oxley Act)¶

    • Financial data integrity

    • Segregation of duties
    • Audit trails
    • Internal controls

    Security Best Practices¶

    Design Phase¶

    1. Least Privilege: Minimum necessary access
    2. Defense in Depth: Multiple security layers
    3. Secure by Default: Start restrictive, open as needed
    4. Data Classification: Identify sensitive data
    5. Compliance Mapping: Map to requirements early

    Implementation Phase¶

    1. Sharing Model: Start with Private OWD
    2. Profiles: Minimal base profiles
    3. Permission Sets: Grant additional access
    4. FLS: Restrict sensitive fields
    5. Validation Rules: Enforce data quality
    6. Encryption: Enable for sensitive data

    Operational Phase¶

    1. Regular Audits: Review access and permissions
    2. Deactivate Users: Remove access promptly
    3. Monitor Events: Track suspicious activity
    4. Patch Management: Keep systems updated
    5. Incident Response: Have a plan
    6. Training: Educate users on security

    Common Security Pitfalls¶

    ❌ Avoid:

    • Public Read/Write OWD (unless necessary)
    • System Admin profile cloning
    • "with sharing" omitted in Apex
    • Hard-coded credentials
    • Disabled FLS in Apex (WITH SECURITY_ENFORCED)
    • Guest user over-permissioning
    • Weak password policies
    • No MFA enforcement

    ✅ Do:

    • Private/Public Read Only OWD
    • Custom profiles from scratch
    • Always use "with sharing"
    • Use Named Credentials
    • Enforce FLS in code
    • Minimal guest user access
    • Strong password policies
    • Mandatory MFA
