    Q: What are the main types of APIs available in Salesforce?¶

    A: Salesforce provides multiple API types to support different integration scenarios and use cases.

    Available API Types:

    • REST API: Modern, lightweight API using JSON for web and mobile applications
    • SOAP API: Enterprise-grade API using XML for complex integrations
    • Bulk API 2.0: High-performance API for processing large data volumes
    • Streaming API: Push-based API for real-time event notifications
    • Metadata API: Manages org configuration and customization metadata
    • Tooling API: Supports development tools and custom development features
    • GraphQL API: Query multiple objects in a single request (beta)

    When to Use Each API:

    • REST API: Modern integrations, mobile apps, single record operations
    • SOAP API: Enterprise systems requiring strict contracts and WSDL
    • Bulk API: Data migrations, batch processing, ETL operations
    • Streaming API: Real-time dashboards, event-driven architectures
    • Metadata API: DevOps, deployment automation, org management
    • Tooling API: IDE development, custom development tools

    Q: What is the difference between synchronous and asynchronous API calls?¶

    A: Synchronous and asynchronous API calls differ in their execution timing and use cases.

    Key Differences:

    • Synchronous: Request waits for response before continuing execution
    • Asynchronous: Request returns immediately, processing continues in background
    • Response Time: Synchronous has immediate response, asynchronous notifies upon completion
    • Use Case: Synchronous for real-time data, asynchronous for large data volumes

    Q: What are API rate limits and how do they work?¶

    A: API rate limits control the number of API requests an organization can make within a specific timeframe to ensure platform stability.

    Rate Limit Types:

    • Daily Limits: Total API calls allowed per 24-hour period
    • Concurrent Limits: Maximum simultaneous API requests
    • Per-User Limits: Limits applied to individual user sessions
    • Burst Limits: Short-term request spikes allowed

    Daily API Limits by Edition:

    • Professional Edition: 1,000 calls per 24 hours
    • Enterprise Edition: Unlimited (subject to org-wide concurrent limits)
    • Unlimited Edition: Unlimited (subject to org-wide concurrent limits)
    • Developer Edition: 15,000 calls per 24 hours

    Concurrent Request Limits:

    • Long-running requests (>20 seconds): 25 concurrent requests
    • Short-running requests (<20 seconds): Higher allowance, dynamically managed
    • Per-org basis: Applies across all users and integrations

public class RateLimitHandler {
    private static final Integer MAX_RETRIES = 3;
    private static final Integer BASE_DELAY = 1000;

    public static HttpResponse makeCalloutWithRetry(HttpRequest req) {
        Http http = new Http();
        Integer retries = 0;

        while (retries < MAX_RETRIES) {
            HttpResponse res = http.send(req);

            if (res.getStatusCode() == 429) { // Too Many Requests
                Integer delay = BASE_DELAY * (Integer)Math.pow(2, retries);
                // In production, use scheduled job for delays
                retries++;
            } else {
                return res;
            }
        }
        throw new CalloutException('Max retries exceeded');
    }
}

    private static final String AUDIENCE = 'https://login.salesforce.com';
    private static final String SUBJECT = 'user@example.com';

    public static String getAccessToken() {
        // Create JWT header
        Map<String, String> header = new Map<String, String>{
            'alg' => 'RS256',
            'typ' => 'JWT'
        };

        // Create JWT payload
        Long now = System.now().getTime() / 1000;
        Map<String, Object> claims = new Map<String, Object>{
            'iss' => ISSUER,
            'sub' => SUBJECT,
            'aud' => AUDIENCE,
            'exp' => now + 3600
        };

        // Sign JWT with private key and exchange for access token
        String assertion = createSignedJWT(header, claims);
        return exchangeJWTForToken(assertion);
    }

    private static String exchangeJWTForToken(String assertion) {
        HttpRequest req = new HttpRequest();
        req.setEndpoint(AUDIENCE + '/services/oauth2/token');

        req.setBody(
            'grant_type=urn:ietf:params:oauth:grant-type:jwt-bearer' +
            '&assertion=' + assertion
        );

        Http http = new Http();
        HttpResponse res = http.send(req);

        Map<String, Object> result = (Map<String, Object>)JSON.deserializeUntyped(res.getBody());
        return (String)result.get('access_token');

        }
    }
}

    Q: What is the Composite API and when should I use it?¶

    A: The Composite API allows you to execute multiple REST API requests in a single call, improving performance and reducing API call limits.

    Key Features:

    • Batch Operations: Execute up to 25 sub-requests in a single call
    • Request Dependencies: Reference results from previous sub-requests
    • All-or-None: Option to rollback all operations if one fails
    • Improved Performance: Reduces network latency and API call count

    Composite API Types:

    • Composite: Execute independent requests in a single call
    • Composite Batch: Similar to Composite, with all-or-none option
    • Composite Graph: Execute dependent requests with automatic ordering
    • SObject Tree: Create multiple related records in a hierarchy

    • Multiple Related Operations: Creating parent and child records together

    • Large Data Volumes: Use Bulk API 2.0 for processing thousands of records

    • Simple Queries: Direct query API is more efficient

    • Complex Operations: Supports compound operations and transactions

    • Legacy Compatibility: Works with older enterprise systems
    • Type Safety: Strong typing reduces integration errors

    SOAP vs REST Comparison:

    • SOAP: XML-based, WSDL contract, enterprise-grade security
    • REST: JSON-based, lightweight, modern web/mobile applications
    • SOAP: Complex operations, describe/metadata operations
    • REST: Simple CRUD operations, stateless architecture

    SOAP API Use Cases:

    • Enterprise Service Bus (ESB) integrations
    • Legacy systems requiring WSDL contracts
    • Complex business process orchestration
    • Systems requiring WS-Security standards
    • Compound operations (describe, metadata retrieval)

public class SOAPQueryProcessor {

    private static final Integer BATCH_SIZE = 2000;

    public static List<Account> queryAllAccounts() {
        List<Account> allAccounts = new List<Account>();
        String queryLocator = null;
        Boolean hasMore = true;

        while (hasMore) {
            Map<String, Object> result = executeQuery(queryLocator);

            List<Object> records = (List<Object>)result.get('records');
            for (Object record : records) {
                // Process each account
                allAccounts.add(parseAccount((Map<String, Object>)record));
            }

            hasMore = (Boolean)result.get('done') == false;
            queryLocator = (String)result.get('queryLocator');
        }

        return allAccounts;
    }

    private static Map<String, Object> executeQuery(String queryLocator) {
        String soapBody;

        if (queryLocator == null) {
            // Initial query
            soapBody = buildQuerySOAP('SELECT Id, Name FROM Account');
        } else {
            // QueryMore for next batch
            soapBody = buildQueryMoreSOAP(queryLocator);
        }

        HttpRequest req = new HttpRequest();
        req.setEndpoint(URL.getOrgDomainUrl().toExternalForm() + '/services/Soap/u/60.0');
        req.setMethod('POST');
        req.setHeader('Content-Type', 'text/xml');
        req.setHeader('SOAPAction', queryLocator == null ? 'query' : 'queryMore');
        req.setBody(soapBody);

        Http http = new Http();
        HttpResponse res = http.send(req);

        return parseQueryResponse(res.getBody());
    }

public class APICacheManager {

    private static final Integer CACHE_TTL_SECONDS = 3600; // 1 hour
    private static Map<String, CacheEntry> memoryCache = new Map<String, CacheEntry>();

    public static String getCachedResponse(String endpoint) {
        // Check memory cache first
        CacheEntry entry = memoryCache.get(endpoint);
        if (entry != null && !entry.isExpired()) {
            System.debug('Cache hit: ' + endpoint);
            return entry.data;
        }

        // Check platform cache
        Cache.OrgPartition orgCache = Cache.Org.getPartition('local.APICache');
        String cachedData = (String)orgCache.get(endpoint);

        if (cachedData != null) {
            System.debug('Platform cache hit: ' + endpoint);
            // Refresh memory cache
            memoryCache.put(endpoint, new CacheEntry(cachedData));
            return cachedData;
        }

        return null;
    }

    public static void cacheResponse(String endpoint, String response) {
        // Store in memory cache
        memoryCache.put(endpoint, new CacheEntry(response));

        // Store in platform cache
        Cache.OrgPartition orgCache = Cache.Org.getPartition('local.APICache');
        orgCache.put(endpoint, response, CACHE_TTL_SECONDS);

        System.debug('Cached response for: ' + endpoint);
    }

    public static void invalidateCache(String endpoint) {
        memoryCache.remove(endpoint);

        Cache.OrgPartition orgCache = Cache.Org.getPartition('local.APICache');
        orgCache.remove(endpoint);

        System.debug('Cache invalidated: ' + endpoint);
    }

    private class CacheEntry {
        public String data;
        public DateTime expiryTime;

        public CacheEntry(String data) {
            this.data = data;
            this.expiryTime = DateTime.now().addSeconds(CACHE_TTL_SECONDS);
        }

        public Boolean isExpired() {
            return DateTime.now() > expiryTime;
        }
    }
}

    private static final Integer PAGE_SIZE = 100;

    public static List<Map<String, Object>> getAllRecords() {
        List<Map<String, Object>> allRecords = new List<Map<String, Object>>();
        Integer page = 1;
        Boolean hasMore = true;

        while (hasMore) {
            Map<String, Object> response = getPage(page);
            List<Object> records = (List<Object>)response.get('records');

            for (Object record : records) {
                allRecords.add((Map<String, Object>)record);
            }

            hasMore = (Boolean)response.get('hasMore');
            page++;

            // Safety limit
            if (page > 10) {
                System.debug('Max pages reached');
                break;
            }
        }

        return allRecords;
    }

    private static Map<String, Object> getPage(Integer pageNumber) {
        HttpRequest req = new HttpRequest();
        req.setEndpoint('callout:External_API/records?page=' + pageNumber + '&size=' + PAGE_SIZE);
        req.setMethod('GET');

        Http http = new Http();
        HttpResponse res = http.send(req);

        if (res.getStatusCode() == 200) {
            return (Map<String, Object>)JSON.deserializeUntyped(res.getBody());
        }

        return new Map<String, Object>{
            'records' => new List<Object>(),
            'hasMore' => false

            System.debug('Status: ' + res.getStatusCode());

        } catch (System.CalloutException e) {
            System.debug('CONNECTION FAILED: ' + e.getMessage());

            if (e.getMessage().contains('Unauthorized endpoint')) {
                System.debug('ERROR: Remote Site Setting missing');
                System.debug('Add to: Setup > Remote Site Settings');
            } else if (e.getMessage().contains('Connection refused')) {
                System.debug('ERROR: Service not reachable');
                System.debug('Check: Firewall, DNS, Service availability');
            } else if (e.getMessage().contains('Read timed out')) {
                System.debug('ERROR: Response timeout');
                System.debug('Check: Network latency, Service performance');
            }
        }
    }
}

    Common Error Codes:

    • 400 Bad Request: Invalid request format or parameters
    • 401 Unauthorized: Authentication failure
    • 403 Forbidden: Insufficient permissions
    • 404 Not Found: Resource doesn't exist
    • 429 Too Many Requests: Rate limit exceeded
    • 500 Internal Server Error: External service error
    • 502/503/504: External service unavailable
